# Code of Conduct

Money Map is an open-source project where people should be able to participate without harassment or intimidation.

## Expected behavior

- Be respectful, patient, and constructive.
- Discuss ideas and code rather than attacking people.
- Welcome contributors with different backgrounds and experience levels.
- Give actionable feedback and assume good intent.
- Protect other people's privacy and never request or publish real financial data.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks
- Sexualized language or unwanted attention
- Publishing another person's private information
- Deliberate disruption, spam, or abusive conduct
- Using project spaces to promote scams or unsafe financial claims

## Reporting

Report unacceptable behavior privately to the repository owner through their GitHub profile. Reports will be reviewed in good faith, and maintainers may edit or remove content, close discussions, or restrict participation when necessary.

## Scope

This code applies to repository discussions, issues, pull requests, reviews, and other spaces where someone represents the Money Map project.
